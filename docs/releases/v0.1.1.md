# YLPlugin v0.1.1 — experimental

Native-backed JavaScript/TypeScript, Java, Kotlin and Python libraries now share
the C++ core and its container validation, permissions, signing and encryption.

* Node-API SDK with ESM/CommonJS exports, TypeScript declarations, exact bigint
  results and byte permission buffers.
* Java 11 JNI SDK with explicit ownership, structured results and key callbacks;
  Kotlin lifecycle and resource helpers.
* Typed Python facade and platform-specific wheels with a bundled native runtime.
* Linux x86_64/ARM64, macOS x86_64/ARM64 and Windows x86_64 SDK build/test coverage.
* Data, WebAssembly host and native C plugin examples alongside RCC and encrypted/
  signed data examples; deterministic fixture inputs across Windows checkouts.
* Expanded documentation and separate, manually dispatched npm/PyPI/Maven Central
  workflows using organization secrets and verified CI artifacts.

Implementation: `f36b5d5e5ba1e20cb060cf8a9f385dd1947310a2`.
[Core CI](https://github.com/YoungLionOrganization/YLPlugin/actions/runs/41705359048)
and [language SDK CI](https://github.com/YoungLionOrganization/YLPlugin/actions/runs/41705359143)
passed. The latter produced five Node prebuilds, five Python platform wheels and
three Maven publications containing all five JNI runtimes. Registry upload status
is reported by the separate publishing workflow; build success alone is not publication.

GitHub core assets contain the source archive, universal Python **facade** wheel,
RCC demo, release manifest and checksums. That universal wheel requires a separately
built native library. Platform wheels are supplied through the language package
pipeline. Linux wheels require manylinux_2_39; see the compatibility guide for npm/
JVM native runtime requirements and other platform limits.

File format/profile 1.0 and C ABI version 1 are unchanged. Windows secure extraction
is unsupported; native plugin execution is not sandboxed. The WASM example uses
an explicit host runtime. No project license grant is made by publication; dependency
licenses are included separately. v0.1.0 remains immutable.
