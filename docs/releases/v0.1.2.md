# YLPlugin v0.1.2 — LGPLv3 licensing

The project owner has selected **GNU LGPL version 3 only** (`LGPL-3.0-only`)
for original YLPlugin code, bindings, tools, examples and documentation.

* Full LGPLv3 text in `LICENSE`, with incorporated GPLv3 terms in `COPYING`.
* SPDX copyright/license notices in maintained source files.
* Matching npm, Python and Maven license metadata and README badges.
* License texts and project/actual-YLSpec source archives included in native
  language distributions; CMake installs license notices too.
* `SOURCES.md` documents source locations, rebuilds and replacement of native modules.
* README installation/architecture examples and registry badges follow YLSpec's
  documentation pattern, adapted to YLPlugin's actual supported capabilities.

The container/profile format and C ABI are unchanged. Existing third-party
components retain their own licenses. Historical 0.1.0/0.1.1 registry files and
tags are immutable; this patch carries the selected license in distributed files.

Use the linked CI results and release manifest for the exact tested commit,
platform results and hashes. Native activation remains unsupported on Windows
because secure extraction is not implemented. This is an experimental SDK.
