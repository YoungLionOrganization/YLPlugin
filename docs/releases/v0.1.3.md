# YLPlugin v0.1.3 — unreleased

Development work; no 0.1.3 release or registry publication has been performed.
The latest published version remains 0.1.2.

* Plaintext store validation uses a bounded streaming hash path instead of
  materializing the whole resource. All bytes are still checked on each call.
* Slice cancellation covers empty resources and the final reader callback.
* Node file opens reject lone UTF-16 surrogates before UTF-8 conversion.
* VERSION changes automatically invalidate CMake configuration for incremental builds.
* New regression tests, an isolated-process benchmark, performance/troubleshooting
  guides, contribution instructions and a GitHub bug-report form.

The recorded 32 MiB Linux comparison measured lower latency and peak process RSS;
see [raw evidence and scope](../performance.md). No universal speed claim is made.
The encrypted/compressed validation path, file/profile formats, C ABI version,
permission semantics and LGPL-3.0-only licensing are unchanged.
