# YLPlugin v0.1.0 — experimental

Initial working implementation of the standalone YLPlugin container, SDK and CLI.

* Own binary container with embedded, unchanged YLSpec framing and profile 1.0.
* C/C++ SDK, Python ctypes facade, indexed resources, store/Zstd and SHA256.
* Host-scoped string/mask/byte permissions, deterministic multi-host preflight.
* Ed25519 signatures and AES-256-GCM payload encryption with host key/trust callbacks.
* Controlled POSIX extraction, data/native adapters and optional memory RCC support.
* Actual RCC sample, conformance vectors, mutation tests and sanitizer/fuzz CI.

Assets contain the source tree, the pure Python facade wheel, a demo package,
a commit/hash manifest and SHA256 checksums. The wheel requires a separately built
native SDK; it does not bundle native binaries or Qt/OpenSSL. Build instructions
are in README.md and docs/building.md. No package registry upload is included.

This release is experimental and is not an independently audited production
security boundary. Windows secure extraction, WASM/Python execution adapters,
mobile/device validation and general foreign runtime vtables remain open.
Native execution is not sandboxed; RCC bytes require host approval. Existing
YLSpec and LeoMiniGames source/loaders are unchanged.
