# Support and Community

YLPlugin is maintained by Cavanshirpro under YoungLionOrganization. Original
project material is LGPL-3.0-only. Published packages are 0.1.2; main prepares
0.1.3 and maintains the documentation and Wiki sources.

## Support development

The repository's owner-configured sponsorship destination is
[YoungLionOrganization on Patreon](https://www.patreon.com/YoungLionOrganization).
It is recorded in [.github/FUNDING.yml](../../.github/FUNDING.yml) and powers the
repository's Sponsor button. The README and Wiki use that configured destination.

## Contribute useful reports

A reproducible report includes the SDK/package and native version, OS/CPU/runtime,
operation/error code, expected/actual behavior and a minimal manifest/resource or
command. Use the repository's Bug report form. A loader/version problem should
first be checked against [Troubleshooting](Troubleshooting.md).

Useful contributions include clear examples, documentation corrections, platform
reproductions and benchmarks that record their inputs/environment. Run the
affected tests and retain license/dependency notices. Read
[Testing and Contributing](Testing-and-Contributing.md) before changing runtime,
ownership, integer, hashing, crypto or extraction behavior.

## Documentation and security

The Wiki explains workflows; normative contracts remain in the source
specification/profile. Corrections can be made in versioned docs/wiki pages and
validated with the publication helper. Suspected security issues should use the
repository's [security policy](../../SECURITY.md) rather than publishing live
credentials or licensed payloads in an issue.
